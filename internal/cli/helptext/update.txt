Change the fields of one issue. Only the flags you pass are written.

To change many issues at once, write one YAML document per issue, each
carrying the id: of the issue it edits, and run
`lit import --path <file.yaml>`. Each document changes the keys it sets,
as this command changes the flags you pass; `lit import --help` lists
them. `lit ls --format yaml` prints a selection of issues in that form,
ready to edit and import back.
